# Алгоритм обучения карты Кохонена

## Блок-схема

```mermaid
flowchart TD
    S([Старт]) --> A

    A["1. Инициализация
        Размер сетки MxN
        Случайные веса
        alpha, sigma"] --> B

    B["2. Начать новую эпоху"] --> C

    C["3. Уменьшить alpha и sigma"] --> D

    D["4. Взять следующий объект X"] --> E

    E["5. Найти нейрон победитель BMU
        минимальное расстояние до X"] --> F

    F["6. Обновить веса BMU и соседей
        W = W + alpha * theta * (X-W)"] --> G

    G{"7. Все объекты обработаны?"} -->|Нет| D

    G -->|Да| H{"8. Все эпохи завершены?"}

    H -->|Нет| B

    H -->|Да| R([Конец])
